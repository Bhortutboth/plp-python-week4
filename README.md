## Assignment Title
PLP Python Week 4 - Functions

## Files

- `welcome.py` - Contains a welcome() function that creates greeting sentences for different names.
- `toolbox.py` - Contains three functions: double(), is_pass(), and greet().

## Hardest Function

The hardest function to write was `greet()` because it uses a default parameter for the greeting. It was important to make sure that "Hello" is used automatically when no greeting is provided, while allowing another greeting such as "Habari" when one is given.
